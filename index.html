Pi Token Analytics

汇总 ~/.pi/agent/sessions 下所有项目的会话消耗，并随时查看原始对话。

只在浏览器本地处理
不会上传会话、命令输出或项目内容

工作方式

统计口径

数据来源

读取 Pi 持久化的 JSONL 会话文件。每一行都是一个 session entry，页面不根据文字长度估算 Token。

四类 Token

total = input + output + cacheRead + cacheWrite

reasoning 已包含在 output 中，不会再次相加。

费用与时间

费用直接读取 usage.cost.total；按每次记录的时间归入天和月，默认使用本地时区。

Pi 的 session 统计会包含已经发生过的历史分支、压缩和摘要消耗。页面会将 assistant、toolResult、compaction、branch_summary 中保存的 usage 一并统计；缺少 usage 的记录不会被猜测，并会在结果中提示。
